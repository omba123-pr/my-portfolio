# Olalekan Idowu — Front-End Engineer Portfolio

A responsive developer portfolio built with HTML, CSS and JavaScript.

## Included
- Responsive navigation
- Hero section
- About section
- Skills
- Selected projects
- Development process
- React.js learning section
- Contact CTA
- Mobile menu

## Before publishing
1. Replace the placeholder email in `index.html`.
2. Replace the GitHub and LinkedIn links with your real profiles.
3. Add real project URLs where available.
4. Add project screenshots later as your projects become portfolio-ready.
5. Deploy with GitHub Pages, Netlify or Vercel.

## Current stack
HTML5, CSS3, JavaScript, React.js (currently learning), Git/GitHub.
